# Vector Barrage — macOS Help

Missile defense — protect six cities

## How to play

Select one of three missile batteries and intercept incoming missiles before they destroy the cities. Watch ammo, bomber warnings and wave telemetry.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Return | Start or advance to the next wave. |
| Mouse click / drag | Fire at target; hold and drag for repeated interceptors. |
| Tab | Cycle left, center, right battery. |
| Space | Fire at the latest cursor position. |
| N | Launch an available nuclear interceptor. |
| T | Redistribute available ammunition. |
| P | Pause or resume. |
| R | Start a new game. |

## Scores, saves and settings

Use the game's Save and Resume buttons to manage local battle snapshots; Custom Game presets are saved separately. Battery ammunition and saved waves remain local to Vector Barrage.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
